TDX Downloader · Windows

在 Windows 上 clone、启动并连接通达信

这份指南面向 Parallels/Windows 11 或独立 Windows 电脑。Windows 侧是真实调用通达信 tqcenter 的环境，因此启动时使用本地模式，不需要 --runtime parallels。

启动前确认

1

Windows 已安装并登录通达信，默认目录建议为 C:\new_tdx64。

2

已安装 Git、Python 3.11+、Node.js LTS。

3

如果使用 Mac 外置盘数据，Parallels 共享路径为 \\psf\ccOUT 1。

一、安装基础工具

Git for Windows

用于 clone GitHub 仓库。安装后重新打开 PowerShell。

Python 3.11+

安装时勾选 Add python.exe to PATH，或使用 py -3.11 启动。

Node.js LTS

用于构建前端页面。安装后用 node -v 和 npm -v 检查。

二、clone 仓库并准备 Python 环境

clone 到 Windows 本地目录

建议放在 Windows 本地盘，速度更稳；数据目录仍可使用共享盘。

mkdir C:\work
cd C:\work
git clone https://github.com/ccyet/tdx-downloader.git
cd tdx-downloader

创建并激活虚拟环境

如果 PowerShell 拦截激活脚本，先临时放开当前窗口执行策略。

py -3.11 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

构建前端页面

仓库不提交 web/dist，Windows 首次运行前需要构建一次。

cd web
npm install
npm run build
cd ..

三、启动服务

保持 PowerShell 窗口打开，服务运行期间页面才能访问。

python -m tdx_downloader.web_api
浏览器打开 http://127.0.0.1:8622/。Windows 上启动后，路径选择按钮会调用系统文件夹选择窗口。

四、页面里的路径怎么填

行情根目录 \\psf\ccOUT 1\tdx-data 或 Windows 本地目录，例如 D:\tdx-data。
TDX PYPlugins/user 默认填 C:\new_tdx64\PYPlugins\user。如果通达信装在其他目录，选择对应的 PYPlugins\user。
复权 原则上使用 qfq，即前复权。
运行模式 Windows 侧直接本地运行，不使用 --runtime parallels。

五、先做连接诊断

正式批量下载前，先确认 Windows 能真实连接通达信。

python -m tdx_downloader.cli tdx-doctor ^
  --symbols 399006.SZ ^
  --timeframes 1d ^
  --start 2026-06-04 ^
  --end 2026-06-05 ^
  --tdx-path "C:\new_tdx64\PYPlugins\user" ^
  --runtime local
如果分钟线返回 no_data，先在 Windows 通达信里下载对应日期的分钟 K 线；程序不会凭空生成通达信本地没有的数据。

六、常见问题

页面打不开

确认 PowerShell 里服务未退出，并访问 http://127.0.0.1:8622/，不是 5173。

文件夹弹窗不出现

服务必须在当前登录桌面用户会话里启动；不要作为 Windows 服务或后台 SYSTEM 会话启动。

无法导入 tqcenter

确认通达信已启动并登录，且 PYPlugins\user 路径填写正确。

共享盘路径不可用

先在资源管理器打开 \\psf\ccOUT 1，确认 Parallels 共享已挂载。

PowerShell 无法激活 venv

执行 Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass 后，再激活虚拟环境。

npm build 报错

确认 Node.js 是 LTS 版本，重新打开 PowerShell 后再执行 npm install。

不要把 API Key、通达信账号密码写进源码或提交到 GitHub。页面里的 AI Key 只应保存在本机浏览器。
